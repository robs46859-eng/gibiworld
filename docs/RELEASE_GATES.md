# GibiWorld — Release Gate Tracker

Cross-cutting gates that block **code freeze** and **launch**, independent of build phase.
`CHECKLIST.md` tracks what is being built; this tracks what must be true before any of it
ships.

**Spec:** GW-ARCH-001 v1.0.0 (baseline 2026-07-31) · **Last verified:** 2026-08-02

**Status key:** `PASS` verified · `PART` partially satisfied · `OPEN` not started ·
`BLOCK` blocked on an external decision or credential

> Gates are ordered by dependency, not by date. A gate cannot pass while any gate it
> depends on is open.

## G3 — Build reproducibility  `BLOCK`

§16 requires builds be reproducible from a signed commit plus a recorded configuration.

- `BLOCK` — **Unity `6000.0.74f1` is not installed.** The machine has `6000.5.2f1`; opening
  the project prompts a version upgrade that breaks reproducibility. CI pins `6000.0.74f1`,
  so local and CI currently disagree.
- `BLOCK` — **NSDK cannot resolve without credentials.** Package is pinned to an immutable
  git tag; access is the missing piece.
- `PASS` — Scenes are generated by `SceneBuilder`, not hand-authored, so scene state is
  diffable and regenerable.
- `PASS` — Package versions frozen in `manifest.json`; deviations require an ADR.
- `PASS` — Android build intermediates untracked and gitignored (2026-08-02).
- `OPEN` — **No iOS XR provider entry.** `XRGeneralSettingsPerBuildTarget` covers Android
  and Standalone only; an iOS build would not start a session.

**To pass:** install the pinned editor, obtain NSDK credentials, add the iOS provider entry,
then produce one green CI build from a clean checkout.

```
G7 (legal sign-off)  ─┐
G3 (reproducibility) ─┼─→ G1 (ADRs accepted) ─→ CODE FREEZE
G4 (traceability)    ─┘         │
                                ├─→ G5 (security)  ─┐
                                ├─→ G6 (privacy)   ─┼─→ G11 ─→ LAUNCH
                                ├─→ G9 (assets)    ─┤
                                └─→ G10 (SLOs)     ─┘

G2 (CI) gates every downstream claim — it is what makes the others verifiable.
G8 (accessibility) runs parallel; blocks launch, not freeze.
```

## Maintaining this file

Re-verify after any release-gate change. The counts in G4 are produced by:

```sh
grep -cE '^\| GW-' docs/TRACEABILITY.md
grep -oE '\| (IMPL|PART|TODO) \|$' docs/TRACEABILITY.md | sort | uniq -c
```

Automate that in CI so the tracker cannot drift the way `CHECKLIST.md`'s counts did.
